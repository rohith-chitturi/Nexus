# Security Policy

NEXUS deals with sensitive metadata and agentic automation.

## Core Tenets
1. **Untrusted Code**: Any SQL, Python, or dbt transformations generated by agents are considered inherently untrusted.
2. **No Direct Production Mutations**: Agents must *never* execute generated code directly against the production database.
3. **Isolated Replay**: All remediation validation occurs in an isolated, deterministic DuckDB replay environment.
4. **Mandatory Human Approval**: No remediation is applied without explicit, recorded human approval.

## Secrets Management
- Do not commit `.env` files, credentials, or API keys.
- Use the `.env.example` file for local reference.
- Use restricted credentials with read-only access for pipeline data connections.
